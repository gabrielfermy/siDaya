# Browser & Screenshot Etiquette Rule

## 1. Minimal Screen Capture Invariant
- **Avoid Automated Screenshot Spam**: Do NOT automatically capture screenshots on every single navigation step, click, or state change during browser sessions or subagent runs.
- **Console & DOM First**: Prioritize inspecting DOM elements, URLs, console logs, and network responses to verify UI state functionally.

## 2. User-Driven Screen Capture Protocol
- If visual verification is needed or a milestone is reached, **ask the user** which specific page, module, or state they want captured before taking screenshots.
- Only capture screenshots when:
  1. The user explicitly requests a screenshot of a specific page or flow.
  2. Confirming a critical visual bug report that the user requested to diagnose.
- When asking, provide clear options (e.g., *"Would you like a screenshot of the Merchant Dashboard, the Barcode Fast-Scan POS, or the Operator Telemetry screen?"*).
